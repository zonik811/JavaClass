## 🤔 ¿Qué es la POO?

### Piensa en un videojuego:

**Sin POO** (todo suelto):
```java
String jugador1Nombre = "Mario";
int jugador1Vida = 100;
int jugador1Nivel = 1;

String jugador2Nombre = "Luigi";
int jugador2Vida = 100;
int jugador2Nivel = 1;
// ¡Necesitas 6 variables para 2 jugadores! 😱
```

**Con POO** (organizado):
```java
// Creas la clase (plano)
Jugador mario = new Jugador("Mario", 100, 1);
Jugador luigi = new Jugador("Luigi", 100, 1);
// ¡Dos jugadores con solo 2 variables! 😎
```

## 📦 Paso 1: Tu Primera Clase

### ¿Qué es una clase?

Una **clase** es un **plano** que define qué tiene y qué hace algo.

### La fórmula mágica:

```java
public class NombreDeLaClase {
    // ATRIBUTOS (lo que TIENE)
    public tipo nombreAtributo;
    
    // MÉTODOS (lo que HACE)
    public void nombreDelMetodo() {
        // código
    }
}
```

### Ejemplo paso a paso: Clase `Robot`

```java
// Paso 1: CREAR la clase (el plano)
public class Robot {
    // ATRIBUTOS (lo que el robot TIENE)
    public String nombre;
    public int bateria;       // 0-100
    public int movimientos;   // cuántos pasos ha dado
    
    // MÉTODO: El robot SALUDA (lo que HACE)
    public void saludar() {
        System.out.println("¡Hola! Soy " + nombre);
        System.out.println("Batería: " + bateria + "%");
        System.out.println("");
    }
    
    // MÉTODO: El robot SE MUEVE
    public void mover() {
        if (bateria > 0) {
            bateria = bateria - 10;
            movimientos = movimientos + 1;
            System.out.println(nombre + " se movió. Bateria: " + bateria + "%");
        } else {
            System.out.println(nombre + ": ❌ Sin batería!");
        }
    }
}
```

### 📖 Paso a paso:

1. **`public class Robot`** → Defines la clase (el plano)
2. **`public String nombre`** → Un atributo (lo que TIENE)
3. **`public int bateria`** → Otro atributo
4. **`public void saludar()`** → Un método (lo que HACE)
5. **`this.nombre`** → Se refiere al atributo de ESTE objeto

---

## 🚀 Paso 2: Crear Objetos (Instanciar)

### ¿Cómo se usa?

```java
public class Main {
    public static void main(String[] args) {
        // Paso 1: CREAR un objeto Robot (instanciar)
        Robot robo1 = new Robot();
        
        // Paso 2: DARLE valores a sus atributos
        robo1.nombre = "R2D2";
        robo1.bateria = 100;
        robo1.movimientos = 0;
        
        // Paso 3: USAR sus métodos
        robo1.saludar();
        robo1.mover();
        robo1.mover();
        robo1.saludar();  // ← Ahora con menos batería
    }
}
```

**Salida**:
```
¡Hola! Soy R2D2
Batería: 100%

R2D2 se movió. Bateria: 90%
R2D2 se movió. Bateria: 80%
¡Hola! Soy R2D2
Batería: 80%
```

### 📖 Paso a paso:

1. **`new Robot()`** → Creas un objeto desde la clase
2. **`robo1.nombre = "R2D2"`** → Le das nombre
3. **`robo1.saludar()`** → Llamas al método del objeto
4. **`robo1.mover()`** → Gasta batería
5. **Cada objeto es independiente** (puedes crear otro robot con otra batería)

    public String nombre;
    public double precio;
    public int stock;
    
    public double valorTotal() {
        return precio * stock;
    }
    
    public void vender(int cantidad) {
        System.out.println("💰 Vendiendo: " + nombre + " x" + cantidad);
        
        if (cantidad <= 0) {
            System.out.println("❌ Cantidad inválida");
        } else if (cantidad > stock) {
            System.out.println("❌ Stock insuficiente. Disponible: " + stock);

            stock = stock - cantidad;
            double ingreso = precio * cantidad;
            System.out.println("✅ Venta exitosa!");
            System.out.println("   Ingreso: $" + ingreso);
            System.out.println("   Stock restante: " + stock);
        }
    }
}

        for (int i = 0; i < longitud; i++) {

// Archivo: Tienda.java
public class Tienda {
    public String nombre;
    public String[] productos;
    public double[] precios;
    public int[] cantidades;
    
    public void mostrarInventario() {
        System.out.println("🏪 INVENTARIO: " + nombre);
        System.out.println("══════════════════\n");
        
        for (int i = 0; i < productos.length; i++) {
            System.out.println("[" + (i + 1) + "] " + productos[i]);
            System.out.println("    Precio: $" + precios[i]);
            System.out.println("    Stock: " + cantidades[i]);

                System.out.println("    ⚠️ AGOTADO");
            } else if (cantidades[i] < 5) {
                System.out.println("    ⚠️ Stock bajo");
            }
            System.out.println("");
        }

    public int buscarProducto(String nombre) {
        for (int i = 0; i < productos.length; i++) {
            if (productos[i].equals(nombre)) {
                return i;
            }
        }
        return -1;

    public double valorTotal() {
        double total = 0;
        for (int i = 0; i < productos.length; i++) {
            total = total + (precios[i] * cantidades[i]);
        }
        return total;
    }

// Archivo: SistemaEscolar.java
public class SistemaEscolar {
    public Estudiante[] estudiantes;
    public int totalEstudiantes;
    
    public SistemaEscolar(int capacidad) {
        estudiantes = new Estudiante[capacidad];
        totalEstudiantes = 0;
    }
    
    public void agregarEstudiante(Estudiante e) {
        if (totalEstudiantes < estudiantes.length) {
            estudiantes[totalEstudiantes] = e;
            totalEstudiantes++;
            System.out.println("✅ " + e.nombre + " agregado!");
        } else {
            System.out.println("❌ Sistema lleno!");
        }
    }
    
    public void mostrarTodos() {
        System.out.println("\n📚 LISTA DE ESTUDIANTES");
        System.out.println("══════════════════\n");
        
        for (int i = 0; i < totalEstudiantes; i++) {
            estudiantes[i].mostrarNotas();
            System.out.println();
        }
    }
    
    public Estudiante mejorPromedio() {
        Estudiante mejor = estudiantes[0];
        double mejorProm = estudiantes[0].calcularPromedio();
        
        for (int i = 1; i < totalEstudiantes; i++) {
            double prom = estudiantes[i].calcularPromedio();
            if (prom > mejorProm) {
                mejorProm = prom;
                mejor = estudiantes[i];
            }
        }
        
        return mejor;
    }

public class Estudiante {

## 🚨 Errores Comunes y Soluciones

### Error: "cannot find symbol" al usar atributo

**Problema**: El atributo no existe en la clase.

**Solución**: Verifica que esté declarado: `public String nombre;`

### Error: NullPointerException

**Problema**: Creaste la variable del objeto pero no usaste `new`.

**Solución**:
```java
// ❌ Mal
Robot r;
r.nombre = "R2D2";  // ¡No existe el objeto aún!

// ✅ Bien
Robot r = new Robot();  // ← Primero CREAR
r.nombre = "R2D2";      // ← Luego USAR
```

### Error: "non-static variable cannot be referenced from static context"

**Problema**: Intentas usar un objeto desde `main()` sin crearlo.

**Solución**: Siempre crea el objeto primero con `new`.

### Error: Atributo no se modifica

**Problema**: Estás modificando una copia local.

**Solución**: Modifica directamente: `this.bateria = bateria - 10;` o `objeto.atributo = valor;`
