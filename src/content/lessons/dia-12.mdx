## 🤔 ¿Qué es un Array?

### La analogía del casillero escolar:

**Sin array** (una variable por dato):
```java
String estudiante1 = "Ana";
String estudiante2 = "Luis";
String estudiante3 = "Pedro";
String estudiante4 = "María";
String estudiante5 = "Carlos";
// ¡Necesitas 5 variables! 😱
```

**Con array** (una variable para todo):
```java
String[] estudiantes = {"Ana", "Luis", "Pedro", "María", "Carlos"};
// ¡Una sola variable! 😎
```

### 🗺️ Diagrama: Cómo se ve por dentro

```
Índice:    [0]      [1]     [2]      [3]       [4]
         ┌─────┬────────┬────────┬────────┬────────┐
         │ Ana │  Luis  │ Pedro  │ María  │ Carlos │
         └─────┴────────┴────────┴────────┴────────┘
```

**¡OJO!** Los índices empiezan en **0**, no en 1.

---

## 📦 Paso 1: Declarar y Acceder

### La fórmula mágica:

```java
// Declarar + crear + llenar (todo en uno)
TIPO[] nombre = {valor1, valor2, valor3};

// Acceder a un valor
nombre[índice]
```

### Ejemplo paso a paso:

```java
public class Main {
    public static void main(String[] args) {
        // Paso 1: CREAR el array
        String[] frutas = {"Manzana", "Banana", "Cereza", "Durazno"};

        // Paso 2: VER cómo se ve
        System.out.println("Índice 0: " + frutas[0]);  // Manzana
        System.out.println("Índice 1: " + frutas[1]);  // Banana
        System.out.println("Índice 2: " + frutas[2]);  // Cereza
        System.out.println("Índice 3: " + frutas[3]);  // Durazno

        // Paso 3: SABER cuántos tiene
        System.out.println("Total: " + frutas.length);  // 4
    }
}
```

### 📖 Paso a paso:

1. **`frutas`** es el nombre del array
2. **`frutas[0]`** → accede al primer elemento (Manzana)
3. **`frutas[1]`** → accede al segundo (Banana)
4. **`frutas.length`** → te dice cuántos hay (4)

## 🚀 Paso 2: Recorrer con `for`

### La fórmula mágica:

```java
for (int i = 0; i < array.length; i++) {
    // array[i] es el elemento actual
}
```

### Ejemplo paso a paso:

```java
public class Main {
    public static void main(String[] args) {
        int[] notas = {85, 92, 78, 95, 88};

        // Vuelta 1: i=0, notas[0]=85
        // Vuelta 2: i=1, notas[1]=92
        // Vuelta 3: i=2, notas[2]=78
        // Vuelta 4: i=3, notas[3]=95
        // Vuelta 5: i=4, notas[4]=88
        // i=5 → 5 < 5 es falso → SALE

        for (int i = 0; i < notas.length; i++) {
            System.out.println("Nota " + (i + 1) + ": " + notas[i]);
        }
    }
}
```

**Salida**:
```
Nota 1: 85
Nota 2: 92
Nota 3: 78
Nota 4: 95
Nota 5: 88
```

<ExerciseBlock id={4} title="Array + while: Búsqueda lineal" difficulty="medium">
  Crea un método `buscarNumero(int[] numeros, int buscado)` que devuelva la posición del número o `-1` si no está.

  <div slot="hint1">
    Usa `int i = 0;` y un `while (i < numeros.length)`.
  </div>

  <div slot="hint2">
    Dentro: `if (numeros[i] == buscado) return i;`. Si sale del while, `return -1;`
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        int[] codigos = {101, 205, 303, 407, 502};

        int pos1 = buscarNumero(codigos, 303);
        System.out.println("303 está en posición: " + pos1);

        int pos2 = buscarNumero(codigos, 999);
        System.out.println("999 está en posición: " + pos2);
    }

    public static int buscarNumero(int[] numeros, int buscado) {
        int i = 0;
        while (i < numeros.length) {
            if (numeros[i] == buscado) {
                return i;  // ← Encontrado!
            }
            i = i + 1;
        }
        return -1;  // ← No encontrado
    }
}
```

**🔍 TRAZA PASO A PASO**:
```
buscarNumero({101, 205, 303, 407, 502}, 303):
  → i=0: 101 == 303 ❌ → i=1
  → i=1: 205 == 303 ❌ → i=2
  → i=2: 303 == 303 ✅ → return 2

buscarNumero({101, 205, 303, 407, 502}, 999):
  → i=0: 101 == 999 ❌ → i=1
  → i=1: 205 == 999 ❌ → i=2
  → i=2: 303 == 999 ❌ → i=3
  → i=3: 407 == 999 ❌ → i=4
  → i=4: 502 == 999 ❌ → i=5
  → 5 < 5 ❌ → SALE del while
  → return -1
```

</ExerciseBlock>

  Crea un método `analizarNotas(double[] notas)` que devuelva un String con:
  - Promedio
  - Nota más alta
  - Nota más baja
  - Cuántos arriba y abajo del promedio

  <div slot="hint1">
    Primero calcula el promedio con un `for`. Luego recorre otra vez para contar.
  </div>

  <div slot="hint2">
    Usa variables: `suma`, `maximo`, `minimo`, `arriba`, `abajo`.
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        double[] notas = {85.5, 92.0, 78.3, 95.7, 88.2, 70.1, 99.0};
        System.out.println(analizarNotas(notas));
    }

    public static String analizarNotas(double[] notas) {
        double suma = 0;
        double maximo = notas[0];
        double minimo = notas[0];
        int arriba = 0;
        int abajo = 0;

        // Primera vuelta: calcular promedio, máximo, mínimo
        for (int i = 0; i < notas.length; i++) {
            suma = suma + notas[i];

            if (notas[i] > maximo) {
                maximo = notas[i];
            }

            if (notas[i] < minimo) {
                minimo = notas[i];
            }
        }

        double promedio = suma / notas.length;

        // Segunda vuelta: contar arriba/abajo
        for (int i = 0; i < notas.length; i++) {
            if (notas[i] >= promedio) {
                arriba++;
            } else {
                abajo++;
            }
        }

        return "📊 ANÁLISIS DE NOTAS\n" +
               "══════════════════\n" +
               "Promedio: " + String.format("%.1f", promedio) + "\n" +
               "Más alta: " + maximo + "\n" +
               "Más baja: " + minimo + "\n" +
               "Arriba del promedio: " + arriba + " estudiantes\n" +
               "Abajo del promedio: " + abajo + " estudiantes";
```

## 🐛 DEBUG MENTAL: Encuentra el error

<ExerciseBlock id={11} title="🐛 ¿Qué está mal en este código?" difficulty="medium">
  Este código tiene **3 errores**. ¿Puedes encontrarlos ANTES de mirar la solución?

  ```java
  // ❌ ESTE CÓDIGO NO FUNCIONA
  public class Main {
      public static void main(String[] args) {
          int[] numeros = {1, 2, 3, 4, 5};

          // Error 1
          for (int i = 0; i <= numeros.length; i++) {
              System.out.println(numeros[i]);
          }

          // Error 2
          int[] copia = numeros;
          copia[0] = 999;
          System.out.println(numeros[0]); // ¿Qué imprime?

          // Error 3
          String[] nombres = {"Ana", "Luis", "Pedro"};
          System.out.println(nombres[3]);
      }
  }
  ```

  <div slot="hint1">
    Error 1: ¿Qué pasa con `<=` en el for? Error 2: ¿`copia` es realmente una copia? Error 3: ¿Existe índice 3?
  </div>

  <div slot="hint2">
    Error 1: `i <= length` accede fuera del array. Error 2: `copia = numeros` no copia, solo referencia. Error 3: Índices 0,1,2 → no hay 3.
  </div>

  <div slot="solution">
```java
// ✅ CÓDIGO CORREGIDO
public class Main {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4, 5};

        // Error 1 corregido: usa < no <=
        for (int i = 0; i < numeros.length; i++) {
            System.out.println(numeros[i]);
        }

        // Error 2 corregido: crear copia real
        int[] copia = new int[numeros.length];
        for (int i = 0; i < numeros.length; i++) {
            copia[i] = numeros[i];
        }
        copia[0] = 999;
        System.out.println(numeros[0]); // Imprime 1 (no 999)

        // Error 3 corregido: índice válido
        String[] nombres = {"Ana", "Luis", "Pedro"};
        System.out.println(nombres[2]); // Pedro (índice 2, no 3)
    }
}
```

**Explicación de los errores**:
1. **`<=` en lugar de `<`** → `i` llega a `length` que no existe. Usa siempre `<`.
2. **`copia = numeros`** → No copia el array, solo copia la referencia. Ambos apuntan al mismo array.
3. **`nombres[3]`** → Solo hay índices 0, 1, 2. El índice 3 no existe.
  </div>
</ExerciseBlock>

## 🚨 Errores Comunes y Soluciones

### Error: "ArrayIndexOutOfBoundsException"

**Problema**: Accediste a un índice que no existe.

**Solución**:
```java
// ❌ Mal
for (int i = 0; i <= array.length; i++) {  // ← Usa < no <=
    System.out.println(array[i]);
}

// ✅ Bien
for (int i = 0; i < array.length; i++) {
    System.out.println(array[i]);
}
```

### Error: "incompatible types" al asignar array

**Problema**: Intentas guardar un tipo en un array de otro tipo.

**Solución**: `int[]` solo acepta `int`, `String[]` solo acepta `String`.

### Error: Array no se modifica

**Problema**: Estás modificando una copia, no el original.

**Solución**: Modifica directamente `array[i] = nuevoValor;` dentro del método.

### Error: NullPointerException con arrays

**Problema**: Intentas usar un array que no fue creado.

**Solución**: Asegúrate de inicializar: `int[] datos = new int[5];` o `int[] datos = {1, 2, 3};`
