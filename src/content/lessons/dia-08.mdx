## 🎯 Objetivo del Día

Hoy conocerás al "rey" de los bucles: el `for`. Es el favorito de los programadores porque permite escribir en **una sola línea** lo que al `while` le toma tres. Es ideal cuando sabemos exactamente cuántas veces queremos repetir algo.

---

## 📋 Antes de Empezar

- El `for` está diseñado específicamente para **contar**.
- Todo lo que hace un `for` se puede hacer con un `while`, pero el `for` es más limpio y organizado.
- Se lee casi como una frase: "Desde que i es 0, mientras i sea menor a 10, aumenta i en 1".

---

## 🏎️ El Bucle `for` (El Especialista)

La estructura del `for` agrupa las tres partes esenciales de un bucle en un solo lugar:

### Estructura:
```java
for (inicialización; condición; actualización) {
    // Código que se repite
}
```

### Ejemplo: El Robot que cuenta del 1 al 5
```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Cati dice: " + i);
}
```

**Las 3 piezas del rompecabezas:**
1. **Inicialización (`int i = 1`)**: Crea la variable y le da un valor inicial. Solo ocurre una vez al empezar.
2. **Condición (`i <= 5`)**: Antes de cada vuelta, pregunta "¿Puedo seguir?". Si es true, entra.
3. **Actualización (`i++`)**: Al final de cada vuelta, cambia el valor (normalmente suma 1).

---

## 💡 ¿Cuándo usar `for` vs `while`?

| Bucle | Úsalo cuando... |
| :--- | :--- |
| **`for`** | Sabes exactamente cuántas vueltas dará (ej: 10 veces, del 1 al 100). |
| **`while`** | No sabes cuántas vueltas dará, depende de una condición externa (ej: hasta que el usuario escriba "salir"). |

<ExerciseBlock id={1} title="Cuenta Regresiva" difficulty="easy">
  Usa un `for` para imprimir una cuenta regresiva del 10 al 1.
  
  <div slot="hint1">Inicia en 10 y usa `i--` como actualización.</div>
  <div slot="solution">
```java
for (int i = 10; i >= 1; i--) {
    System.out.println(i);
}
```

for (int i = 0; i <= 20; i += 2) {

  </div>

<ExerciseBlock id={3} title="Tabla del 7" difficulty="medium">

  <div slot="solution">

for (int i = 1; i <= 10; i++) {

  </div>

<ExerciseBlock id={4} title="Suma de los primeros 10" difficulty="medium">
  Calcula la suma de los números del 1 al 10 y muestra el total.
  
  <div slot="hint1">Crea una variable `int suma = 0` ANTES del bucle.</div>
  <div slot="solution">
```java
int suma = 0;
for (int i = 1; i <= 10; i++) {
    suma += i;
}
System.out.println("La suma es: " + suma);

  </div>
</ExerciseBlock>

<ExerciseBlock id={5} title="El Grito del Robot" difficulty="easy">

Scanner sc = new Scanner(System.in);
System.out.print("¿Cuántas veces grito?: ");
int veces = sc.nextInt();

for (int i = 0; i < veces; i++) {
    System.out.println("¡HOLA!");
}
```
  </div>

<ExerciseBlock id={8} title="Calculadora de Potencia" difficulty="hard">
  Calcula 2 elevado a la 10 (2^10) usando un bucle `for` (sin usar Math.pow).
  
  <div slot="hint1">Inicia `resultado = 1` y multiplícalo por 2 en cada una de las 10 vueltas.</div>
  <div slot="solution">
```java
int base = 2;
int potencia = 1;
for (int i = 1; i <= 10; i++) {
    potencia *= base;
}
System.out.println("2 elevado a 10 es: " + potencia);
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={9} title="Cuadrados Perfectos" difficulty="medium">
  Imprime el cuadrado de cada número del 1 al 10 (ej: 1, 4, 9, 16...).
  
  <div slot="solution">
```java
for (int i = 1; i <= 10; i++) {
    System.out.println("El cuadrado de " + i + " es " + (i * i));
}
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={10} title="Dibujando una Línea" difficulty="hard">
  Pide un número y dibuja una línea de asteriscos `*` de ese largo.
  
  <div slot="hint1">Usa `System.out.print("*")` (sin 'ln') para que salgan en la misma línea.</div>
  <div slot="solution">
```java
int largo = 10;
for (int i = 0; i < largo; i++) {
    System.out.print("*");
}
System.out.println(); // Salto de línea al final
```
  </div>
</ExerciseBlock>
