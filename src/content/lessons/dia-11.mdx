## 🔄 Repaso Rápido (2 minutos)

### Void vs Retorno:

```java
// VOID: Solo HACE algo (imprime)
public static void saludar(String nombre) {
    System.out.println("Hola, " + nombre);
}
// Uso: saludar("Ana");  ← No guarda nada

// RETORNO: CALCULA y DEVUELVE algo
public static String generarSaludo(String nombre) {
    return "Hola, " + nombre;
}
// Uso: String msg = generarSaludo("Ana");  ← Guarda el resultado
```

---

## 🤔 ¿Qué es un Método con Retorno?

### La analogía de la máquina expendedora:

**Void**: Le das una moneda y la máquina hace algo (imprime un recibo). No recibes nada de vuelta.

**Con retorno**: Le das monedas y la máquina **te devuelve** un producto + cambio.

### La diferencia visual:

**Método `void`** (ya lo sabes):
```java
public static void saludar(String nombre) {
    System.out.println("Hola, " + nombre);  // Solo imprime
}
// Lo llamas: saludar("Oscar");
// No te devuelve nada, solo imprime
```

**Método con retorno** (nuevo):
```java
public static String generarSaludo(String nombre) {
    return "Hola, " + nombre;  // ← DEVUELVE el texto
}
// Lo llamas: String mensaje = generarSaludo("Oscar");
// ¡Ahora tienes el valor guardado para usarlo después!
```

### 🗺️ Diagrama: ¿Cómo Funciona `return`?

```
┌─────────────────────────────────────────┐
│  main() empieza                         │
│    ↓                                    │
│  int resultado = sumar(5, 3) ────────┐  │
│    ↓                                 │  │
│  (main se PAUSA, espera valor)       │  │
│    ↓                                 │  │
│                                ┌──────▼──────┐
│                                │ sumar(5, 3) │
│                                │ a=5, b=3    │
│                                │   ↓         │
│                                │ suma = 8    │
│                                │   ↓         │
│                                │ return 8 ───┼──┐
│                                └─────────────┘  │
│                                                 │
│    ↓                                  ◄────────┘
│  resultado = 8  (el valor REGRESÓ)
│    ↓
│  System.out.println("5+3=" + resultado)
│    ↓
│  Imprime: "5+3=8"
└─────────────────────────────────────────┘
```

### La fórmula mágica:

```java
public static TIPO_DE_RETORNO nombreDelMetodo(parámetros) {
    // Tu código
    return valor;  // ← Devuelve algo del TIPO que declaraste
}
```

### Ejemplo paso a paso:

```java
public class Main {
    public static void main(String[] args) {
        // Paso 1: LLAMAS al método y GUARDAS el resultado
        int resultado = sumar(5, 3);

        // Paso 2: USAS el resultado
        System.out.println("5 + 3 = " + resultado);

        // Paso 3: También puedes usarlo directamente
        System.out.println("10 + 7 = " + sumar(10, 7));
    }

    // Aquí defines el método con RETORNO
    public static int sumar(int a, int b) {
        int suma = a + b;
        return suma;  // ← Devuelve el valor a quien llamó
    }
}
```

### 🔍 TRAZA PASO A PASO:

```
sumar(5, 3):
  → a = 5, b = 3
  → suma = 5 + 3 = 8
  → return 8  ← El valor 8 REGRESA a main()
  → resultado = 8
  → Imprime "5 + 3 = 8"

sumar(10, 7):
  → a = 10, b = 7
  → suma = 10 + 7 = 17
  → return 17  ← El valor 17 REGRESA directamente al println
  → Imprime "10 + 7 = 17"
```

## 🚀 Paso 2: Múltiples `return` con `if`

Un método puede tener **varios `return`**, pero **solo se ejecuta uno**:

```java
public static String verificarEdad(int edad) {
    if (edad >= 18) {
        return "✅ Mayor de edad";  // ← Si entra aquí, SALE
    } else {
        return "❌ Menor de edad";  // ← Si entra aquí, SALE
    }
    // Nunca llega aquí porque ya retornó
}
```

### 🔍 TRAZA PASO A PASO:

```
verificarEdad(20):
  → edad = 20
  → 20 >= 18 ✅ → entra al if
  → return "✅ Mayor de edad"  ← SALE INMEDIATAMENTE
  → El valor REGRESA a quien llamó

verificarEdad(15):
  → edad = 15
  → 15 >= 18 ❌ → salta al else
  → return "❌ Menor de edad"  ← SALE INMEDIATAMENTE
  → El valor REGRESA a quien llamó
```

### ⚠️ Regla importante:

**Cuando Java ejecuta un `return`, SALE del método inmediatamente.** Todo código después del `return` NUNCA se ejecuta.

```java
// ❌ Mal - código inalcanzable
public static int ejemplo(int x) {
    return x * 2;
    System.out.println("Esto nunca se ejecuta");  // ERROR!
}

// ✅ Bien
public static int ejemplo(int x) {
    System.out.println("Esto SÍ se ejecuta");
    return x * 2;
}
```

<ExerciseBlock id={8} title="🐛 DEBUG MENTAL: Encuentra el error en métodos con retorno" difficulty="hard">
  Este código tiene **3 errores**. ¿Puedes encontrarlos?

  ```java
  // ❌ ESTE CÓDIGO NO FUNCIONA
  public class Main {
      public static void main(String[] args) {
          System.out.println(doble(5));
      }

      public static int doble(int x) {
          if (x > 0) {
              return x * 2;
          }
          // Error 1: ¿Qué pasa si x <= 0?
      }

      public static String comparar(int a, int b) {
          if (a > b)
              return a + " es mayor";
          else if (a < b)
              return b + " es mayor";
          // Error 2: ¿Y si a == b?

      }

      public static void saludar() {
          return "Hola";  // Error 3: ¿void puede retornar String?
      }
  }
  ```

  <div slot="hint1">
    Error 1: Si x es negativo, no hay return. Error 2: Falta el caso a==b. Error 3: void no puede retornar valor.
  </div>

  <div slot="hint2">
    Cada método necesita un return para TODOS los caminos posibles. Y el tipo de return debe coincidir con la declaración.
  </div>

  <div slot="solution">
```java
// ✅ CÓDIGO CORREGIDO
public class Main {
    public static void main(String[] args) {
        System.out.println("Doble de 5: " + doble(5));
        System.out.println("Doble de -3: " + doble(-3));
        System.out.println(comparar(5, 3));
        System.out.println(comparar(3, 3));
    }

    // Error 1 corregido: agregar return para el caso negativo
    public static int doble(int x) {
        if (x > 0) {
            return x * 2;
        }
        return 0;  // ← Return por defecto para negativos
    }

    // Error 2 corregido: agregar caso a == b
    public static String comparar(int a, int b) {
        if (a > b)
            return a + " es mayor";
        else if (a < b)
            return b + " es mayor";
        else
            return "Son iguales";  // ← Caso faltante
    }

    // Error 3 corregido: cambiar void a String
    public static String saludar() {
        return "Hola";
    }
}
```

**Explicación de los errores**:
1. **Falta return** → Si `x <= 0`, el método no retorna nada. Java exige `return` en TODOS los caminos.
2. **Caso faltante** → Si `a == b`, ninguno de los `if` se ejecuta. Necesitas un `return` final.
3. **Tipo incorrecto** → `void` significa "no retorna nada". Si pones `return "Hola"`, el método debe ser `String`.
  </div>
</ExerciseBlock>

        String resultado = simularBatalla(100, 80, 15, 20);
        System.out.println(resultado);
    }

    public static String simularBatalla(int vidaHeroe, int vidaMonstruo, int dañoHeroe, int dañoMonstruo) {
        int turnos = 0;

        while (vidaHeroe > 0 && vidaMonstruo > 0) {
            turnos++;
            vidaMonstruo = vidaMonstruo - dañoHeroe;
            vidaHeroe = vidaHeroe - dañoMonstruo;
        }

        if (vidaMonstruo <= 0) {
            return "🎉 Héroe gana en " + turnos + " turnos!";
        } else {
            return "👾 Monstruo gana en " + turnos + " turnos!";
        }
    }
}

## 🚨 Errores Comunes y Soluciones

### Error: "missing return statement"

**Problema**: Java no encuentra un `return` en algún camino del método.

**Solución**: Asegúrate de que **todos los caminos** llegen a un `return`:
```java
// ❌ Mal
public static int ejemplo(int x) {
    if (x > 0) {
        return x;
    }
    // Si x <= 0, no hay return!
}

// ✅ Bien
public static int ejemplo(int x) {
    if (x > 0) {
        return x;
    }
    return -1;  // ← Caso por defecto
}
```

### Error: "incompatible types" en return

**Problema**: Declaraste `int` pero retornas `double`.

**Solución**: Asegúrate de que el tipo del `return` coincida con la declaración.

### Error: "unreachable statement" después de return

**Problema**: Pusiste código después de un `return` (nunca se ejecutará).

**Solución**: Mueve el código **antes** del `return`.

### Error: Bucle infinito en método con return

**Problema**: El `while` nunca encuentra la condición para hacer `return`.

**Solución**: Verifica que la variable de control cambie: `i = i + 1;`
