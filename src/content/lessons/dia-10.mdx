## 🔄 Repaso Rápido (2 minutos)

Antes de empezar, recordemos las 3 herramientas que ya conoces:

### 🔀 if / else if / else
```java
if (edad >= 18) {
    System.out.println("Mayor de edad");
} else {
    System.out.println("Menor de edad");
}
```
**Para qué sirve**: Tomar decisiones (SI pasa algo → haz esto, SINO → haz esto otro)

### 🔁 for
```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Vuelta " + i);
}
```
**Para qué sirve**: Repetir algo un **número conocido** de veces (1, 2, 3, 4, 5)

### 🔁 while
```java
int energia = 100;
while (energia > 0) {
    energia = energia - 10;
    System.out.println("Energía: " + energia);
}
```
**Para qué sirve**: Repetir algo **mientras se cumpla una condición** (no sabes cuántas vueltas)

## 🤔 ¿Qué es un Método?

### Piensa en esto como controles de videojuego:

**Sin métodos**: Escribes TODO el código del juego en un solo archivo (¡imposible de mantener!)

**Con métodos**: Separas en funciones:
- `moverPersonaje()` ← este hace una cosa
- `mostrarPuntaje()` ← este hace otra
- `verificarColision()` ← este hace otra más

### En código:

**Sin métodos** (un desastre):
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("=== MENÚ ===");
        System.out.println("1. Agregar");
        System.out.println("2. Ver");
        System.out.println("Producto: Laptop x5");
        System.out.println("Producto: Mouse x20");
    }
}
```

**Con métodos** (organizado):
```java
public class Main {
    public static void main(String[] args) {
        mostrarMenu();
        mostrarProducto("Laptop", 5);
        mostrarProducto("Mouse", 20);
    }

    public static void mostrarMenu() {
        System.out.println("=== MENÚ ===");
        System.out.println("1. Agregar");
        System.out.println("2. Ver");
    }

    public static void mostrarProducto(String nombre, int cantidad) {
        System.out.println("Producto: " + nombre + " x" + cantidad);
    }
}
```

**¿Ves la diferencia?** Ahora puedes reutilizar `mostrarProducto()` sin repetir código.

## 🗺️ Diagrama: ¿Cómo Funciona un Método?

### El flujo paso a paso:

```
┌─────────────────────────────────────────┐
│  main() empieza                         │
│    ↓                                    │
│  Llama a: saludar("Ana")  ───────────┐  │
│    ↓                                 │  │
│  (main se PAUSA)                     │  │
│    ↓                                 │  │
│                                ┌──────▼──────┐
│                                │ saludar()   │
│                                │ nombre="Ana"│
│                                │   ↓         │
│                                │ Imprime     │
│                                │   ↓         │
│                                │ Termina     │
│                                └──────┬──────┘
│                                       │  RETURN
│    ↓                                  │
│  (main CONTINÚA)  ◄───────────────────┘
│    ↓
│  Siguiente línea de main()
└─────────────────────────────────────────┘
```

### 📖 En palabras simples:

1. **Java empieza en `main()`** (siempre empieza aquí)
2. **Encuentra `saludar("Ana");`** → SALTA al método `saludar`
3. **`main()` se PAUSA** (espera a que `saludar` termine)
4. **`saludar()` ejecuta TODO su código** con `nombre = "Ana"`
5. **Cuando termina** → REGRESA a `main()` exactamente donde se quedó
6. **`main()` CONTINÚA** con la siguiente línea

## 📦 Paso 1: Estructura de un Método `void`

### ¿Qué significa `void`?

`void` = "Este método NO devuelve nada, solo hace algo"

**Ejemplo**: `mostrarMensaje()` solo imprime, no devuelve ningún valor.

### La fórmula mágica:

```java
public static void nombreDelMetodo() {
    // Tu código aquí
}
```

### Tu primer método:

```java
public class Main {
    public static void main(String[] args) {
        saludar();  // ← LLAMAS al método
    }

    // Aquí defines qué hace el método
    public static void saludar() {
        System.out.println("¡Hola! Bienvenido.");
        System.out.println("Hoy aprenderás métodos.");
    }
}
```

**Salida**:
```
¡Hola! Bienvenido.
Hoy aprenderás métodos.
```

## 🚀 Paso 2: Métodos con Parámetros

### ¿Qué es un parámetro?

Es **información que le das** al método para que la use.

**Ejemplo**: `saludar("Oscar")` le das el nombre para que lo use.

### Ejemplo con parámetro:

```java
public class Main {
    public static void main(String[] args) {
        repetirLinea("Hola", 3);
        repetirLinea("Mundo", 2);
    }

    public static void repetirLinea(String texto, int veces) {
        for (int i = 1; i <= veces; i++) {
            System.out.println(texto + " (vez " + i + ")");
        }
    }
}
```

### 🔍 TRAZA PASO A PASO (¡MIRA cómo funciona!):

```
Llamada 1: repetirLinea("Hola", 3)
  → texto = "Hola", veces = 3
  → for: i=1, 1<=3 ✅ → "Hola (vez 1)"
  → for: i=2, 2<=3 ✅ → "Hola (vez 2)"
  → for: i=3, 3<=3 ✅ → "Hola (vez 3)"
  → for: i=4, 4<=3 ❌ → SALE del for
  → Método TERMINA, regresa a main()

Llamada 2: repetirLinea("Mundo", 2)
  → texto = "Mundo", veces = 2
  → for: i=1, 1<=2 ✅ → "Mundo (vez 1)"
  → for: i=2, 2<=2 ✅ → "Mundo (vez 2)"
  → for: i=3, 3<=2 ❌ → SALE del for
  → Método TERMINA, regresa a main()
```

**Salida**:
```
Hola (vez 1)
Hola (vez 2)
Hola (vez 3)
Mundo (vez 1)
Mundo (vez 2)
```

<ExerciseBlock id={10} title="🐛 DEBUG MENTAL: Encuentra el error" difficulty="medium">
  Este código tiene **3 errores**. ¿Puedes encontrarlos ANTES de mirar la solución?

  ```java
  // ❌ ESTE CÓDIGO NO FUNCIONA - Encuentra los errores
  public class Main {
      public static void main(String[] args) {
          saludar("Ana");
      }

      public static void saludar(String nombre) {
          System.out.println("Hola " + nombres)  // Error 1: falta ;
      }
  }

  public class Main {  // Error 2: clase duplicada
      public static void main(String[] args) {
          contar(5);
      }

      public static void contar(int maximo) {
          for (int i = 1; i <= maximo; i++);  // Error 3: ; después del for
          {
              System.out.println(i);
          }
      }
  }
  ```

  <div slot="hint1">
    Error 1: Mira el final de la línea del println. Error 2: ¿Puedes tener 2 clases Main? Error 3: ¿Qué pasa si pones ; después del for?
  </div>

  <div slot="hint2">
    Error 1: Falta `;`. Error 2: Solo puede haber UNA clase Main. Error 3: El `;` hace que el for no ejecute nada, y `i` no existe fuera del for.
  </div>

  <div slot="solution">
```java
// ✅ CÓDIGO CORREGIDO
public class Main {
    public static void main(String[] args) {
        saludar("Ana");
        contar(5);
    }

    // Error 1 corregido: agregado ;
    public static void saludar(String nombre) {
        System.out.println("Hola " + nombre);
    }

    // Error 2 corregido: todo en una sola clase
    // Error 3 corregido: eliminado ; después del for
    public static void contar(int maximo) {
        for (int i = 1; i <= maximo; i++) {
            System.out.println(i);
        }
    }
}
```

**Explicación de los errores**:
1. **Falta `;`** → Java necesita `;` al final de cada instrucción
2. **Dos clases Main** → Solo puede haber una clase pública por archivo
3. **`;` después del `for`** → `for (...);` = "repite NADA N veces". Luego `{ System.out.println(i); }` se ejecuta UNA sola vez, y `i` no existe ahí.
  </div>

## 🚨 Errores Comunes y Soluciones

### Error: "cannot find symbol: method saludar()"

**Problema**: El método no existe o está mal escrito.

**Solución**:
1. Verifica que el método `saludar()` exista en tu clase
2. Revisa que los paréntesis `()` estén presentes
3. Verifica que esté escrito correctamente (mayúsculas/minúsculas)

### Error: "';' expected" en la llamada al método

**Problema**: Olvidaste el punto y coma al llamar el método.

**Solución**: Agrega `;` al final: `saludar();`

### Error: "incompatible types" en parámetros

**Problema**: Le diste el tipo de dato equivocado al método.

**Solución**: Si el método espera `String nombre`, no le des un número: `saludar("Oscar")` ✅, `saludar(5)` ❌

### Error: El método se define pero nunca se ejecuta

**Problema**: Definiste el método, pero nunca lo llamaste desde `main()`.

**Solución**: Agrega la llamada en `main()`: `saludar();`

### Error: `;` después del `for` o `while`

**Problema**: `for (int i = 0; i < 5; i++);` ← El `;` hace que el bucle no haga nada.

**Solución**: Nunca pongas `;` inmediatamente después de `for(...)` o `while(...)`.
