## 🚀 Paso 1: For-Each (La Forma Rápida)

### ¿Qué es?

Es un `for` simplificado cuando **solo necesitas leer** los elementos (no el índice).

### La fórmula mágica:

```java
// For normal (cuando necesitas el índice)
for (int i = 0; i < array.length; i++) {
    System.out.println("Índice " + i + ": " + array[i]);
}

// For-Each (cuando solo necesitas el valor)
for (TIPO elemento : array) {
    System.out.println("Valor: " + elemento);
}
```

### Ejemplo paso a paso:

```java
public class Main {
    public static void main(String[] args) {
        String[] colores = {"Rojo", "Verde", "Azul", "Amarillo"};

        // For-Each: "Para cada color en colores..."
        for (String color : colores) {
            System.out.println("Color: " + color);
        }
    }
}
```

**Salida**:
```
Color: Rojo
Color: Verde
Color: Azul
Color: Amarillo
```

### 📖 Paso a paso:

1. **Java toma el primer elemento** ("Rojo")
2. **Lo guarda en `color`**
3. **Ejecuta el código** dentro del for-each
4. **Pasa al siguiente** ("Verde")
5. **Repite** hasta terminar

### ⚠️ Cuándo NO usar for-each:

```java
// ❌ No puedes modificar el array con for-each
for (int num : numeros) {
    num = num * 2;  // ¡No funciona!
}

// ✅ Usa for normal si necesitas modificar
for (int i = 0; i < numeros.length; i++) {
    numeros[i] = numeros[i] * 2;  // ¡Funciona!
}
```

<ExerciseBlock id={3} title="Búsqueda avanzada: Encontrar todos los índices" difficulty="medium">
  Crea un método `encontrarTodos(String[] palabras, String buscada)` que devuelva un String con TODAS las posiciones donde aparece la palabra.

  <div slot="hint1">
    Usa `String resultado = "";` y un `for` normal para tener el índice.
  </div>

  <div slot="hint2">
    Dentro: `if (palabras[i].equals(buscada))` → agrega `i` al resultado.
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        String[] animales = {"gato", "perro", "gato", "pájaro", "gato", "pez"};
        System.out.println(encontrarTodos(animales, "gato"));
        System.out.println(encontrarTodos(animales, "perro"));
        System.out.println(encontrarTodos(animales, "serpiente"));
    }

    public static String encontrarTodos(String[] palabras, String buscada) {
        String resultado = "'" + buscada + "' encontrado en posiciones: ";
        boolean encontrado = false;

        for (int i = 0; i < palabras.length; i++) {
            if (palabras[i].equals(buscada)) {
                if (encontrado) {
                    resultado += ", ";
                }
                resultado += i;
                encontrado = true;
            }
        }

        if (!encontrado) {
            return "❌ '" + buscada + "' no encontrado";
        }

        return resultado;
    }
```

```java
            for (int j = 0; j < tabla[i].length; j++) {
                System.out.print(tabla[i][j] + "\t");
            }

        }
    }
```

<ExerciseBlock id={8} title="Ordenamiento básico: Burbuja" difficulty="hard">
  Crea un método `ordenarArray(int[] numeros)` que ordene los números de menor a mayor usando el algoritmo de burbuja.

  <div slot="hint1">
    Usa dos `for` anidados. Compara `numeros[j]` con `numeros[j+1]` y swap si están desordenados.
  </div>

  <div slot="hint2">
    El `for` externo va de `0` a `length-1`. El interno va de `0` a `length-1-i`.
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        int[] datos = {64, 34, 25, 12, 22, 11, 90};
        System.out.println("Original: " + arrayAString(datos));

        ordenarArray(datos);

        System.out.println("Ordenado: " + arrayAString(datos));
    }

    public static int[] ordenarArray(int[] numeros) {
        int n = numeros.length;

        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (numeros[j] > numeros[j + 1]) {
                    // Swap (intercambiar)
                    int temp = numeros[j];
                    numeros[j] = numeros[j + 1];
                    numeros[j + 1] = temp;
                }
            }
        }

        return numeros;
    }

    public static String arrayAString(int[] array) {
        String resultado = "";
        for (int i = 0; i < array.length; i++) {
            if (i > 0) resultado += ", ";
            resultado += array[i];
        }
        return resultado;
    }
}
```

**🔍 TRAZA PASO A PASO** (primera pasada):
```
{64, 34, 25, 12, 22, 11, 90}
  → j=0: 64 > 34 ✅ → swap → {34, 64, 25, 12, 22, 11, 90}
  → j=1: 64 > 25 ✅ → swap → {34, 25, 64, 12, 22, 11, 90}
  → j=2: 64 > 12 ✅ → swap → {34, 25, 12, 64, 22, 11, 90}
  → j=3: 64 > 22 ✅ → swap → {34, 25, 12, 22, 64, 11, 90}
  → j=4: 64 > 11 ✅ → swap → {34, 25, 12, 22, 11, 64, 90}
  → j=5: 64 > 90 ❌ → no swap
  → 90 está en su lugar!
```

</ExerciseBlock>

<ExerciseBlock id={10} title="Simulación: Sistema de calificaciones 2D" difficulty="hard">

<ExerciseBlock id={11} title="🐛 ¿Qué está mal en este código?" difficulty="medium">
  Este código tiene **3 errores**. ¿Puedes encontrarlos ANTES de mirar la solución?

  ```java
  // ❌ ESTE CÓDIGO NO FUNCIONA
  public class Main {
      public static void main(String[] args) {
          // Error 1: For-each para modificar
          int[] numeros = {1, 2, 3};
          for (int n : numeros) {
              n = n * 2;  // ¿Funciona?
          }
          System.out.println(numeros[0]);  // ¿Qué imprime?

          // Error 2: Array 2D mal accedido
          int[][] matriz = {{1, 2}, {3, 4}};
          System.out.println(matriz[2][0]);  // ¿Existe?

          // Error 3: Confundir length
          String[][] tabla = new String[3][5];
          System.out.println(tabla.length);      // ¿Qué imprime?
          System.out.println(tabla[0].length);   // ¿Qué imprime?
      }
  }
  ```

  <div slot="hint1">
    Error 1: For-each no modifica. Error 2: Índice 2 no existe en 2 filas. Error 3: length vs [0].length.
  </div>

  <div slot="hint2">
    Error 1: Usa for normal. Error 2: Índices 0,1 solo. Error 3: 3 filas, 5 columnas.
  </div>

  <div slot="solution">
```java
// ✅ CÓDIGO CORREGIDO
public class Main {
    public static void main(String[] args) {
        // Error 1 corregido: usar for normal para modificar
        int[] numeros = {1, 2, 3};
        for (int i = 0; i < numeros.length; i++) {
            numeros[i] = numeros[i] * 2;
        }
        System.out.println(numeros[0]);  // Imprime 2

        // Error 2 corregido: índice válido
        int[][] matriz = {{1, 2}, {3, 4}};
        System.out.println(matriz[1][0]);  // Imprime 3 (índice 1 existe)

        // Error 3: Esto SÍ funciona, pero entendamos:
        String[][] tabla = new String[3][5];
        System.out.println(tabla.length);      // 3 (filas)
        System.out.println(tabla[0].length);   // 5 (columnas)
    }
}
```

**Explicación de los errores**:
1. **For-each no modifica** → `n` es una copia local. Usa `for (int i = 0; i <.length; i++)`.
2. **Índice fuera de rango** → `matriz[2]` no existe (solo 0 y 1).
3. **`length` vs `[0].length`** → `.length` = filas, `[0].length` = columnas.

<ExerciseBlock id={12} title="Mini-Proyecto: Registro de temperaturas" difficulty="hard">
  Crea un método `analizarTemperaturas(double[][] temperaturas, String[] ciudades)` donde cada fila es una ciudad y cada columna es un día de la semana. Devuelve un reporte con promedios, máxima y mínima.

  <div slot="hint1">
    `temperaturas[i][j]` = temperatura de la ciudad `i` en el día `j`.
  </div>

  <div slot="hint2">
    Calcula: promedio por ciudad, temperatura máxima global, temperatura mínima global.
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        String[] ciudades = {"Madrid", "Barcelona", "Sevilla"};
        double[][] temperaturas = {
            {22, 24, 23, 25, 21, 20, 22},  // Madrid
            {18, 19, 20, 21, 17, 18, 19},  // Barcelona
            {30, 32, 31, 33, 29, 28, 30}   // Sevilla
        };

        System.out.println(analizarTemperaturas(temperaturas, ciudades));
    }

    public static String analizarTemperaturas(double[][] temperaturas, String[] ciudades) {
        String reporte = "🌡️ REPORTE DE TEMPERATURAS\n";
        reporte += "══════════════════════════════\n\n";

        double maxGlobal = temperaturas[0][0];
        double minGlobal = temperaturas[0][0];
        String ciudadMax = "";
        String ciudadMin = "";

        for (int i = 0; i < ciudades.length; i++) {
            double suma = 0;
            double maxCiudad = temperaturas[i][0];
            double minCiudad = temperaturas[i][0];

            for (int j = 0; j < temperaturas[i].length; j++) {
                double temp = temperaturas[i][j];
                suma = suma + temp;

                if (temp > maxGlobal) {
                    maxGlobal = temp;
                    ciudadMax = ciudades[i];
                }
                if (temp < minGlobal) {
                    minGlobal = temp;
                    ciudadMin = ciudades[i];
                }
                if (temp > maxCiudad) maxCiudad = temp;
                if (temp < minCiudad) minCiudad = temp;
            }

            double promedio = suma / temperaturas[i].length;

            reporte += ciudades[i] + ":\n";
            reporte += "  Promedio: " + String.format("%.1f", promedio) + "°C\n";
            reporte += "  Máxima: " + maxCiudad + "°C\n";
            reporte += "  Mínima: " + minCiudad + "°C\n\n";
        }

        reporte += "──────────────────────────────\n";
        reporte += "🔥 Más caliente: " + ciudadMax + " (" + maxGlobal + "°C)\n";
        reporte += "❄️ Más fría: " + ciudadMin + " (" + minGlobal + "°C)";

        return reporte;
    }
}
```

<ExerciseBlock id={13} title="Mini-Proyecto: Simulador de bingo" difficulty="hard">
  Crea un método `simularBingo(int[][] cartones, int[] bolasSacadas)` que simule un juego de bingo y devuelva qué cartón ganó y en qué bola.

  <div slot="hint1">
    Cada cartón es `cartones[i][j]`. Cada bola sacada se busca en todos los cartones.
  </div>

  <div slot="hint2">
    Marca los números acertados y verifica si un cartón está completo.
  </div>

  <div slot="solution">
```java
public class Main {
    public static void main(String[] args) {
        int[][] cartones = {
            {5, 12, 23, 34, 45},   // Cartón 1
            {8, 15, 28, 31, 42},   // Cartón 2
            {3, 18, 22, 39, 48}    // Cartón 3
        };
        int[] bolasSacadas = {7, 15, 23, 31, 42, 8, 28, 5, 12, 34, 45};

        System.out.println(simularBingo(cartones, bolasSacadas));
    }

    public static String simularBingo(int[][] cartones, int[] bolasSacadas) {
        String log = "🎱 SIMULACIÓN DE BINGO\n";
        log += "══════════════════\n\n";

        // Marcar cartones
        boolean[][] marcados = new boolean[cartones.length][cartones[0].length];

        for (int b = 0; b < bolasSacadas.length; b++) {
            int bola = bolasSacadas[b];
            log += "Bola " + (b + 1) + ": " + bola + "\n";

            // Buscar en todos los cartones
            for (int i = 0; i < cartones.length; i++) {
                for (int j = 0; j < cartones[i].length; j++) {
                    if (cartones[i][j] == bola) {
                        marcados[i][j] = true;
                        log += "  ✅ Cartón " + (i + 1) + ": " + bola + " marcado\n";
                    }
                }
            }

            // Verificar si algún cartón está completo
            for (int i = 0; i < cartones.length; i++) {
                if (cartonCompleto(marcados, i)) {
                    log += "\n🎉 ¡BINGO! Cartón " + (i + 1) + " gana con la bola " + (b + 1) + "!";
                    return log;
                }
            }
        }

        log += "\n❌ Ningún cartón completó";
        return log;
    }

    public static boolean cartonCompleto(boolean[][] marcados, int cartonIndex) {
        for (int j = 0; j < marcados[cartonIndex].length; j++) {
            if (!marcados[cartonIndex][j]) {
                return false;
            }
        }
        return true;
    }
}
```

## 🚨 Errores Comunes y Soluciones

### Error: "ArrayIndexOutOfBoundsException" en array 2D

**Problema**: Accediste a una fila/columna que no existe.

**Solución**:
```java
// ✅ Verifica límites
for (int i = 0; i < matriz.length; i++) {           // Filas
    for (int j = 0; j < matriz[i].length; j++) {    // Columnas
        System.out.println(matriz[i][j]);
    }
}
```

### Error: For-each no modifica el array

**Problema**: Intentas cambiar valores con for-each.

**Solución**: Usa `for` normal con índice para modificar:
```java
// ❌ No funciona
for (int num : numeros) {
    num = num * 2;
}

// ✅ Funciona
for (int i = 0; i < numeros.length; i++) {
    numeros[i] = numeros[i] * 2;
}
```

### Error: Swap incorrecto

**Problema**: Al intercambiar valores, pierdes uno.

**Solución**: Usa una variable temporal:
```java
// ✅ Correcto
int temp = a;
a = b;
b = temp;
```

### Error: Confundir `length` en arrays 2D

**Problema**: Usas `array.length` para columnas.

**Solución**:
- `array.length` = número de **filas**
- `array[i].length` = número de **columnas** en la fila `i`
