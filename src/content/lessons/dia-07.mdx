## 🎯 Objetivo del Día

Hoy aprenderás a hacer que tu código se **repita** automáticamente. No más copiar y pegar la misma línea 10 veces. Veremos cómo usar `while` (mientras) y `do-while` (haz-mientras) para controlar repeticiones.

---

## 📋 Antes de Empezar

- Los bucles son como una **canción en repeat**: se detienen solo cuando la condición cambia.
- ¡Cuidado con los **bucles infinitos**! Es cuando el código nunca para (como un robot dando vueltas sin fin).
- Usaremos variables que cambian en cada vuelta (contadores).

---

## 🔄 El Bucle `while` (El Vigilante)

El `while` primero **pregunta** y luego **actúa**. Solo entra si la respuesta es "Sí" (true).

### Estructura:
```java
while (condicion) {
    // Código que se repite
}
```

### Ejemplo: El Robot Contador (1 al 5)
```java
int contador = 1;

while (contador <= 5) {
    System.out.println("Vuelta número: " + contador);
    contador++; // ¡IMPORTANTE! Si no sumas, el bucle nunca termina
}
```

**Paso a paso:**
1. Empezamos en 1.
2. ¿1 es menor o igual a 5? **Sí**. Imprime "Vuelta 1" y suma 1 (ahora es 2).
3. ¿2 es menor o igual a 5? **Sí**. Imprime "Vuelta 2" y suma 1.
4. ... así hasta que el contador llega a 6.
5. ¿6 es menor o igual a 5? **Nop**. El bucle se rompe. 🛑

---

## 🔁 El Bucle `do-while` (El Decidido)

El `do-while` primero **actúa** y luego **pregunta**. Siempre se ejecuta **al menos una vez**.

### Estructura:
```java
do {
    // Código que se repite
} while (condicion);
```

### Ejemplo: Pidiendo el PIN
```java
int pin;
Scanner teclado = new Scanner(System.in);

do {
    System.out.print("Introduce tu PIN: ");
    pin = teclado.nextInt();
} while (pin != 1234);

System.out.println("¡Acceso concedido!");
```

**Diferencia clave:**
- `while`: Puede no ejecutarse nunca si la condición es falsa desde el inicio.
- `do-while`: Se ejecuta 1 vez sí o sí, aunque la condición sea falsa después.

<ExerciseBlock id={2} title="La Cuenta Regresiva" difficulty="easy">
  Imprime los números del 5 al 1 (hacia atrás) y al final que diga "¡Despegue! 🚀".
  
  <div slot="hint1">Empieza en 5 y usa `contador--` para restar.</div>
  <div slot="hint2">La condición debe ser `contador > 0`.</div>
  
  <div slot="solution">

```java
int i = 5;
while (i > 0) {
    System.out.println(i);
    i--;
}
System.out.println("¡Despegue! 🚀");
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={3} title="Solo Pares" difficulty="medium">
  Imprime solo los números pares del 2 al 20 usando un salto de +2.
  
  <div slot="hint1">Inicia en 2. En lugar de `i++`, usa `i = i + 2`.</div>
  <div slot="solution">
```java
int i = 2;
while (i <= 20) {
    System.out.println(i);
    i += 2;
}
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={4} title="Suma Acumulada" difficulty="medium">
  Suma todos los números del 1 al 100 y muestra el resultado final.
  
  <div slot="hint1">Necesitas dos variables: un `contador` y una `suma`.</div>
  <div slot="solution">
```java
int i = 1;
int suma = 0;
while (i <= 100) {
    suma += i;
    i++;
}
System.out.println("La suma total es: " + suma);
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={5} title="Bucle do-while de Seguridad" difficulty="medium">
  Pide por teclado una respuesta de "S" o "N" hasta que el usuario escriba algo válido.
  
  <div slot="hint1">Usa `do-while` para preguntar al menos una vez.</div>
  <div slot="solution">
```java
Scanner sc = new Scanner(System.in);
char respuesta;
do {
    System.out.print("¿Deseas continuar? (S/N): ");
    respuesta = sc.next().charAt(0);
} while (respuesta != 'S' && respuesta != 'N');
```
  </div>
</ExerciseBlock>
