## 🎯 Objetivo del Día

Hoy aprenderás a ser el "director" de tus bucles. Veremos cómo detener un bucle de golpe con `break`, cómo saltarnos una vuelta con `continue` y, lo más emocionante, cómo meter un bucle dentro de otro para crear patrones y rejillas.

---

## 🛑 `break`: El Freno de Mano

El `break` sirve para salir de un bucle **inmediatamente**, sin importar si la condición todavía era verdadera.

### Ejemplo: Buscando un número prohibido
```java
for (int i = 1; i <= 10; i++) {
    if (i == 7) {
        System.out.println("¡Encontré el 7! Deteniendo...");
        break; // El bucle se detiene aquí y no llega al 8, 9 ni 10.
    }
    System.out.println("Número: " + i);
}
```

---

## ⏭️ `continue`: El Botón de Saltar

El `continue` no detiene el bucle, sino que **se salta el resto del código** de la vuelta actual y pasa directamente a la siguiente.

### Ejemplo: El Robot que odia el número 3
```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue; // Salta el print para el número 3 y sigue con el 4.
    }
    System.out.println("Contando: " + i);
}
// Resultado: 1, 2, 4, 5 (el 3 no aparece)
```

---

## 🔄 Bucles Anidados: El Reloj

Un bucle anidado es simplemente **un bucle dentro de otro**. Es como un reloj: el bucle de adentro (minutos) tiene que dar una vuelta completa para que el de afuera (horas) avance un paso.

### Ejemplo: Una Rejilla de Coordenadas (3x3)
```java
for (int i = 1; i <= 3; i++) { // Bucle de Filas
    for (int j = 1; j <= 3; j++) { // Bucle de Columnas
        System.out.print("(" + i + "," + j + ") ");
    }
    System.out.println(); // Salto de línea al terminar cada fila
}
```

**Resultado:**
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
(3,1) (3,2) (3,3)

<ExerciseBlock id={4} title="Tablas de Multiplicar (1 al 5)" difficulty="hard">
  Usa bucles anidados para imprimir las tablas de multiplicar del 1, 2, 3, 4 y 5.
  
  <div slot="hint1">El bucle exterior controla de qué número es la tabla, el interior multiplica del 1 al 10.</div>
  <div slot="solution">

```java
    System.out.println("Tabla del " + i + ":");

    }
    System.out.println(); // Espacio entre tablas
}
```
  </div>
</ExerciseBlock>

<ExerciseBlock id={5} title="Suma hasta Limite" difficulty="medium">
  Crea un bucle que sume números del 1 al 100, pero detente si la suma supera los 500.
  
  <div slot="solution">
```java
int suma = 0;
for (int i = 1; i <= 100; i++) {
    suma += i;
    if (suma > 500) {
        System.out.println("Limite superado en " + i);
        break;
    }
}
System.out.println("Suma total: " + suma);
```
  </div>
</ExerciseBlock>
