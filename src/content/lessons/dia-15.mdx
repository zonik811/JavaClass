## 📋 Antes de Empezar

- **Ya sabes crear clases** con atributos y métodos

- **El problema**: Dar valores a cada atributo uno por uno es lento
- **La solución**: El **constructor** te permite dar valores al crear

## 🤔 ¿Qué es un Constructor?

### El problema (sin constructor):

```java
// Así lo hacías antes (lento)
Robot r = new Robot();
r.nombre = "R2D2";
r.bateria = 100;
r.movimientos = 0;
r.nivel = 1;
// ¡4 líneas solo para inicializar! 😩
```

### La solución (con constructor):

```java
// Así lo harás hoy (rápido)
Robot r = new Robot("R2D2", 100);
// ¡Una sola línea! 😎
```

### La fórmula mágica:

```java
public class NombreClase {
    public tipo atributo1;
    public tipo atributo2;
    
    // CONSTRUCTOR (mismo nombre que la clase, sin return)
    public NombreClase(tipo valor1, tipo valor2) {
        this.atributo1 = valor1;
        this.atributo2 = valor2;
    }
}
```

## 📦 Paso 1: Tu Primer Constructor

### Ejemplo paso a paso: Clase `Robot` con constructor

```java
// Archivo: Robot.java
public class Robot {
    // ATRIBUTOS
    public String nombre;
    public int bateria;
    public int movimientos;
    public int nivel;
    
    // CONSTRUCTOR
    public Robot(String nombre, int bateriaInicial) {
        this.nombre = nombre;           // ← El nombre de ESTE robot
        this.bateria = bateriaInicial;  // ← La batería de ESTE robot
        this.movimientos = 0;           // ← Valor por defecto
        this.nivel = 1;                 // ← Valor por defecto
    }
    
    // MÉTODO: Saludar
    public void saludar() {
        System.out.println("🤖 Soy " + nombre);
        System.out.println("   Batería: " + bateria + "% | Nivel: " + nivel);
        System.out.println("   Movimientos: " + movimientos);
        System.out.println("");
    }
    
    // MÉTODO: Moverse (gasta batería)
    public void mover() {
        if (bateria >= 10) {
            bateria = bateria - 10;
            movimientos = movimientos + 1;
            System.out.println(nombre + " se movió. Bateria: " + bateria + "%");
        } else {
            System.out.println(nombre + ": ❌ Batería baja! (" + bateria + "%)");
        }
    }
    
    // MÉTODO: Cargar batería
    public void cargarBateria(int cantidad) {
        bateria = bateria + cantidad;
        
        if (bateria > 100) {
            bateria = 100;  // No puede pasar de 100
        }
        
        System.out.println(nombre + " cargó " + cantidad + "%. Batería: " + bateria + "%");
    }
}
```

### 📖 Paso a paso del constructor:

1. **`public Robot(String nombre, int bateriaInicial)`**
   - Mismo nombre que la clase
   - Sin `void`, sin `return`
   - Con parámetros

2. **`this.nombre = nombre;`**
   - `this.nombre` = el atributo de ESTE objeto
   - `nombre` = el parámetro que recibiste

3. **Valores por defecto**: `movimientos = 0`, `nivel = 1`
   - No los pasas como parámetro, los inicializas dentro

### Cómo se usa:

```java
// Archivo: Main.java
public class Main {
    public static void main(String[] args) {
        // Crear robots CON constructor (una línea cada uno)
        Robot r1 = new Robot("R2D2", 100);
        Robot r2 = new Robot("Wall-E", 80);
        Robot r3 = new Robot("BB-8", 60);
        
        r1.saludar();
        r2.saludar();
        r3.saludar();
        
        // Usar métodos
        r1.mover();
        r2.mover();
        r3.cargarBateria(20);
    }
}
```

## 🚀 Paso 2: Múltiples Constructores (Sobrecarga)

Puedes tener **varios constructores** con diferentes parámetros:

```java
public class Robot {
    public String nombre;
    public int bateria;
    public int nivel;
    
    // Constructor con todo
    public Robot(String nombre, int bateria, int nivel) {
        this.nombre = nombre;
        this.bateria = bateria;
        this.nivel = nivel;
    }
    
    // Constructor simple (solo nombre, batería por defecto)
    public Robot(String nombre) {
        this.nombre = nombre;
        this.bateria = 100;  // ← Valor por defecto
        this.nivel = 1;      // ← Valor por defecto
    }
}

// Uso:
Robot r1 = new Robot("R2D2", 100, 5);  // Constructor completo
Robot r2 = new Robot("Wall-E");         // Constructor simple
```

## 🚨 Errores Comunes y Soluciones

### Error: "constructor ... cannot be applied to given types"

**Problema**: Pasaste parámetros incorrectos al constructor.

**Solución**:
```java
// ❌ Mal
Robot r = new Robot("R2D2");  // Si el constructor pide 3 parámetros

// ✅ Bien
Robot r = new Robot("R2D2", 100, 1);
```

### Error: "return type required" en constructor

**Problema**: Pusiste `void` en el constructor.

**Solución**: Los constructores **NO** tienen tipo de retorno:
```java
// ❌ Mal
public void Robot(String nombre) { }

// ✅ Bien
public Robot(String nombre) { }
```

### Error: this.nombre no funciona

**Problema**: No hay atributo con ese nombre.

**Solución**: Verifica que `nombre` esté declarado como atributo de la clase.
