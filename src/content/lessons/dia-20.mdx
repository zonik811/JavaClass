## 🤔 ¿Qué es una Excepción?

### La analogía del paracaídas:

**Sin try/catch** (sin paracaídas):
```java
int resultado = 10 / 0;  // 💥 ¡¡¡ERROR!!! El programa MUERE
System.out.println("Esto nunca se ejecuta");
```

**Con try/catch** (con paracaídas):
```java
try {
    int resultado = 10 / 0;  // ← Error
} catch (ArithmeticException e) {
    System.out.println("❌ No puedes dividir por cero!");
}
System.out.println("✅ El programa continúa");
```

## 📦 Paso 1: try/catch Básico

### La fórmula mágica:

```java
try {
    // Código que PUEDE fallar
    códigoPeligroso();
} catch (TipoDeExcepción e) {
    // Qué hacer si FALLA
    System.out.println("Error: " + e.getMessage());
} finally {
    // SIEMPRE se ejecuta (opcional)
    System.out.println("Limpieza...");
}
```

### Ejemplo paso a paso:

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.print("Ingresa un número: ");
        String input = sc.nextLine();
        
        try {
            // Paso 1: Intentar convertir
            int numero = Integer.parseInt(input);
            
            // Paso 2: Intentar dividir
            int resultado = 100 / numero;
            
            // Paso 3: Si todo salió bien
            System.out.println("100 / " + numero + " = " + resultado);
            
        } catch (NumberFormatException e) {
            // Error: no es un número
            System.out.println("❌ Eso no es un número válido!");
            
        } catch (ArithmeticException e) {
            // Error: división por cero
            System.out.println("❌ No puedes dividir por cero!");
            
        } catch (Exception e) {
            // Error: cualquier otra cosa
            System.out.println("❌ Error inesperado: " + e.getMessage());
        } finally {
            // Siempre se ejecuta
            System.out.println("✅ Programa continuando normalmente...");
        }
        
        System.out.println("Adiós!");
    }
}
```

### 📖 Paso a paso:

1. **`try`** → Intenta ejecutar este código
2. **Si funciona** → salta todos los `catch`
3. **Si falla** → busca el `catch` que coincide con el error
4. **`finally`** → siempre se ejecuta (limpieza, cerrar archivos, etc.)

## 🚀 Paso 2: `throw` (Lanzar excepciones)

### ¿Qué es?

Es **crear tu propio error** cuando algo no está bien.

### La fórmula mágica:

```java
public void setEdad(int edad) {
    if (edad < 0 || edad > 150) {
        throw new IllegalArgumentException("Edad inválida: " + edad);
    }
    this.edad = edad;
}
```

### Ejemplo completo:

```java
public class CuentaBancaria {
    private double saldo;
    
    public void retirar(double cantidad) {
        if (cantidad < 0) {
            throw new IllegalArgumentException("Cantidad negativa: " + cantidad);
        }
        if (cantidad > saldo) {
            throw new IllegalStateException("Fondos insuficientes. Saldo: $" + saldo);
        }
        
        saldo -= cantidad;
        System.out.println("✅ Retiro exitoso: $" + cantidad);
    }
}

// Uso:
public class Main {
    public static void main(String[] args) {
        CuentaBancaria cuenta = new CuentaBancaria();
        
        try {
            cuenta.retirar(-100);  // ← Lanzará excepción
        } catch (IllegalArgumentException e) {
            System.out.println("❌ " + e.getMessage());
        }
    }
}
```

    public ContraseñaInvalidaException(String mensaje) {

// Archivo: ValidadorContraseña.java
public class ValidadorContraseña {
    public static void validar(String contraseña) throws ContraseñaInvalidaException {
        if (contraseña.length() < 8) {
            throw new ContraseñaInvalidaException("Debe tener al menos 8 caracteres");
        }
        
        boolean tieneMayuscula = false;
        boolean tieneNumero = false;
        boolean tieneEspecial = false;
        
        for (int i = 0; i < contraseña.length(); i++) {
            char c = contraseña.charAt(i);
            if (Character.isUpperCase(c)) tieneMayuscula = true;
            if (Character.isDigit(c)) tieneNumero = true;
            if ("!@#$%^&*".indexOf(c) != -1) tieneEspecial = true;
        }
        
        if (!tieneMayuscula) {
            throw new ContraseñaInvalidaException("Debe tener al menos una mayúscula");
        }
        if (!tieneNumero) {
            throw new ContraseñaInvalidaException("Debe tener al menos un número");
        }
        if (!tieneEspecial) {
            throw new ContraseñaInvalidaException("Debe tener al menos un carácter especial (!@#$%^&*)");
        }
        
        System.out.println("✅ Contraseña válida!");
    }
}

// Archivo: Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("🔒 VALIDADOR DE CONTRASEÑAS\n");
        
        while (true) {
            System.out.print("Ingresa contraseña (o 'salir'): ");
            String pass = sc.nextLine();
            
            if (pass.equalsIgnoreCase("salir")) break;
            
            try {
                ValidadorContraseña.validar(pass);
            } catch (ContraseñaInvalidaException e) {
                System.out.println("❌ " + e.getMessage());
            } catch (Exception e) {
                System.out.println("❌ Error inesperado: " + e.getMessage());
            }
            
            System.out.println();

public class InventarioSeguro {
    private String[] productos;
    private double[] precios;
    private int total;
    
    public InventarioSeguro(int capacidad) {
        this.productos = new String[capacidad];
        this.precios = new double[capacidad];
        this.total = 0;
    }
    
    public void agregarProducto(String nombre, String precioStr) {
        if (total >= productos.length) {
            System.out.println("❌ Inventario lleno!");
            return;
        }
        
        try {
            double precio = Double.parseDouble(precioStr);
            
            if (precio < 0) {
                System.out.println("❌ Precio no puede ser negativo");
                return;
            }
            
            productos[total] = nombre;
            precios[total] = precio;
            total++;
            System.out.println("✅ " + nombre + " agregado ($" + precio + ")");
            
        } catch (NumberFormatException e) {
            System.out.println("❌ Precio inválido: " + precioStr);
        }
    }
    
    public void verProducto(int indice) {
        try {
            System.out.println("📦 " + productos[indice]);
            System.out.println("   Precio: $" + precios[indice]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("❌ Producto #" + indice + " no existe (total: " + total + ")");
        }
    }
    
    public void mostrarTodo() {
        System.out.println("\n📋 INVENTARIO:");
        for (int i = 0; i < total; i++) {
            System.out.println("[" + i + "] " + productos[i] + " - $" + precios[i]);
        }
    }
}

// Cuenta Bancaria
public class CuentaBancaria {
    private String titular;
    private double saldo;
    private boolean abierta;

public class Personaje {
    private String nombre;
    private int vida;
    private int vidaMax;
    private int ataque;
    private int defensa;
    private int nivel;
    private int experiencia;
    private int pociones;
    
    public Personaje(String nombre, int vida, int ataque, int defensa) {
        this.nombre = nombre;
        this.vida = vida;
        this.vidaMax = vida;
        this.ataque = ataque;
        this.defensa = defensa;
        this.nivel = 1;
        this.experiencia = 0;
        this.pociones = 3;
    }
    
    // GETTERS
    public String getNombre() { return nombre; }
    public int getVida() { return vida; }
    public int getVidaMax() { return vidaMax; }
    public int getAtaque() { return ataque; }
    public int getDefensa() { return defensa; }
    public int getNivel() { return nivel; }
    public int getExperiencia() { return experiencia; }
    public int getPociones() { return pociones; }
    
    public boolean estaVivo() {
        return vida > 0;
    }
    
    public void recibirDaño(int daño) {
        int dañoReal = Math.max(0, daño - defensa);
        vida = Math.max(0, vida - dañoReal);
        System.out.println("💥 " + nombre + " recibió " + dañoReal + " de daño! (HP: " + vida + "/" + vidaMax + ")");
    }
    
    public void atacar(Enemigo enemigo) {
        int daño = (int)(Math.random() * ataque) + 5;
        System.out.println("⚔️ " + nombre + " ataca a " + enemigo.getNombre() + " por " + daño + " de daño!");
        enemigo.recibirDaño(daño);
    }
    
    public void usarPocion() {
        if (pociones > 0) {
            int curacion = 30;
            vida = Math.min(vidaMax, vida + curacion);
            pociones--;
            System.out.println("🧪 " + nombre + " usó poción! +" + curacion + " HP (HP: " + vida + "/" + vidaMax + ")");
        } else {
            System.out.println("❌ " + nombre + " no tiene pociones!");
        }
    }
    
    public void ganarExperiencia(int exp) {
        experiencia += exp;
        System.out.println("✨ " + nombre + " ganó " + exp + " de experiencia!");
        
        if (experiencia >= nivel * 100) {
            subirNivel();
        }

        nivel++;
        experiencia = 0;
        vidaMax += 10;
        vida = vidaMax;
        ataque += 5;
        defensa += 3;
        pociones++;
        System.out.println("🎉 ¡" + nombre + " subió al nivel " + nivel + "!");

        System.out.println("   ✨ EXP: " + experiencia + "/" + (nivel * 100));

  Crea la clase `Batalla` que maneje el combate con validación de errores.

  <div slot="hint1">

// Archivo: Batalla.java
public class Batalla {
    public static void combate(Personaje heroe, Enemigo enemigo) {
        System.out.println("\n⚔️ ═══════════════════════════");
        System.out.println("   BATALLA: " + heroe.getNombre() + " vs " + enemigo.getNombre());
        System.out.println("═══════════════════════════\n");
        
        int turno = 1;
        
        try {
            while (heroe.estaVivo() && enemigo.estaVivo()) {
                System.out.println("--- Turno " + turno + " ---");
                
                // Héroe ataca
                heroe.atacar(enemigo);
                
                if (!enemigo.estaVivo()) {
                    System.out.println("\n🎉 ¡" + enemigo.getNombre() + " derrotado!");
                    heroe.ganarExperiencia(enemigo.getExpReward());
                    return;
                }
                
                // Enemigo ataca
                enemigo.atacar(heroe);
                
                if (!heroe.estaVivo()) {
                    System.out.println("\n💀 ¡" + heroe.getNombre() + " ha caído...");
                    return;
                }
                
                turno++;
                System.out.println();
            }
        } catch (Exception e) {
            System.out.println("\n❌ Error en batalla: " + e.getMessage());
        }
    }
}

public class Mapa {
    private String[][] mapa;
    private String[] nombresZonas;
    
    public Mapa() {
        this.mapa = new String[][]{
            {"aldea", "bosque", "bosque", "cueva"},
            {"bosque", "montaña", "cueva", "cueva"},
            {"montaña", "montaña", "pantano", "castillo"},
            {"aldea", "montaña", "pantano", "castillo"}

        this.nombresZonas = new String[]{

            "Montaña Helada", "Pantano Maldito", "Castillo del Dragón"
        };
    }
    
    public String getZona(int x, int y) {
        try {
            return mapa[y][x];
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("❌ Zona fuera del mapa!");
            return "aldea";
        }
    }
    
    public Enemigo generarEnemigo(String zona) {
        try {
            double random = Math.random();
            
            switch (zona) {
                case "aldea":
                    return null;  // Zona segura
                case "bosque":
                    return new Slime();
                case "cueva":
                    return new Esqueleto();
                case "castillo":
                    return new Dragon();
                default:
                    return new Slime();
            }
        } catch (Exception e) {
            System.out.println("❌ Error generando enemigo: " + e.getMessage());
            return new Slime();
        }
    }
    
    public void mostrarMapa(int px, int py) {
        System.out.println("\n🗺️ MAPA DEL MUNDO");

                        case "bosque": System.out.print("🌲"); break;
                        case "cueva": System.out.print("🕳️"); break;
                        case "montaña": System.out.print("⛰️"); break;
                        case "pantano": System.out.print("🌊"); break;
                        case "castillo": System.out.print("🏰"); break;
                        default: System.out.print("❓");
                    }
                }
            }
            System.out.println();
        }

## 🚨 Errores Comunes y Soluciones

### Error: "unreported exception ... must be caught or declared"

**Problema**: Llamaste un método que lanza excepción sin try/catch.

**Solución**: Envuelve en try/catch o declara `throws` en tu método.

### Error: Catch genérico captura todo

**Problema**: Usas `catch (Exception e)` y no sabes qué error específico fue.

**Solución**: Usa catch específicos primero, genérico al final:
```java
try {
    // código
} catch (NumberFormatException e) {
    // Específico primero
} catch (Exception e) {
    // Genérico último
}
```

### Error: finally con return

**Problema**: Pones `return` en finally que sobrescribe el return del try.

**Solución**: No pongas `return` en finally.
