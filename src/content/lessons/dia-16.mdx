## 🎯 Objetivo del Día

Hoy aprenderás **Encapsulación**: proteger los datos de tus objetos para que nadie los modifique directamente. Usarás `private`, `public`, **getters** y **setters** con validaciones `if`.

---

## 📋 Antes de Empezar

- **Ya sabes crear clases** con constructores
- **Ya sabes usar métodos** con `if`, `for`, `while`
- **El problema**: Con `public`, cualquiera puede poner datos inválidos
- **La solución**: `private` + getters/setters (control total)

---

## 🤔 ¿Por qué Encapsular?

### El problema (sin encapsulación):

```java
// Cualquiera puede hacer esto:
CuentaBancaria cuenta = new CuentaBancaria("Ana", 1000);
cuenta.saldo = -5000;  // ¡¡¡SALDO NEGATIVO!!! 😱
cuenta.titular = "";   // ¡Titular vacío!
```

### La solución (con encapsulación):

```java
CuentaBancaria cuenta = new CuentaBancaria("Ana", 1000);
// cuenta.saldo = -5000;  // ❌ ERROR! No se puede acceder directo
cuenta.retirar(500);      // ✅ El método VALIDA antes
```

---

## 📦 Paso 1: `private` vs `public`

### La diferencia:

| Modificador | ¿Quién puede acceder? |
|-------------|----------------------|
| `public` | **Todos** (cualquier código) |
| `private` | **Solo la propia clase** |

### Ejemplo visual:

```java
public class CuentaBancaria {
    // PRIVATE: Solo esta clase puede modificar
    private String titular;
    private double saldo;
    private String numeroCuenta;
    
    // PUBLIC: Todos pueden llamar
    public void mostrarInfo() {
        System.out.println(titular + ": $" + saldo);
    }
}
```

### Qué pasa si intentas acceder:

```java
CuentaBancaria cuenta = new CuentaBancaria("Ana", 1000);

// ❌ ERROR! Son private
cuenta.saldo = 5000;
cuenta.titular = "Luis";

// ✅ OK! Llamas al método public
cuenta.mostrarInfo();
```

---

## 🚀 Paso 2: Getters y Setters

### ¿Qué son?

- **Getter**: Método que **devuelve** el valor de un atributo privado
- **Setter**: Método que **asigna** el valor con validación `if`

### La fórmula mágica:

```java
// GETTER (solo leer)
public tipo getNombre() {
    return this.nombre;
}

// SETTER (cambiar con validación)
public void setNombre(tipo nuevoValor) {
    if (nuevoValor es válido) {
        this.nombre = nuevoValor;
    } else {
        System.out.println("❌ Valor inválido");
    }
}
```

```java
    private double precio;
    private int stock;

        this.precio = precio;
        this.setStock(stock);  // Usa el setter con validación
    }

    public double getPrecio() { return this.precio; }
    public int getStock() { return this.stock; }

        if (stock >= 0) {

        } else {
            System.out.println("❌ Stock no puede ser negativo");

    }
    
    public void setPrecio(double precio) {

            this.precio = precio;
        } else {
            System.out.println("❌ Precio debe ser positivo");

            System.out.println("❌ Cantidad inválida");

            System.out.println("❌ Stock insuficiente. Disponible: " + stock);
            return false;

        double ingreso = precio * cantidad;
        System.out.println("✅ Vendido: " + nombre + " x" + cantidad + " → $" + ingreso);
        System.out.println("   Stock restante: " + stock);
        return true;
    }
    
    public void reabastecer(int cantidad) {
        if (cantidad > 0) {
            stock = stock + cantidad;
            System.out.println("✅ Reabastecido: " + nombre + " +" + cantidad + " unidades");

            System.out.println("❌ Cantidad inválida");
        }
    }
}
```

<ExerciseBlock id={4} title="Estudiante con notas protegidas" difficulty="medium">
  Crea una clase `Estudiante` con `private double[] notas`. Solo se pueden modificar con método `setNota()`.

  <div slot="hint1">
    `setNota(int materia, double nota)` valida índice y rango (0-100).
  </div>

  <div slot="hint2">
    `getPromedio()` recorre el array con `for` y devuelve el promedio.
  </div>

  <div slot="solution">
```java
// Archivo: Estudiante.java
public class Estudiante {
    private String nombre;
    private String[] materias;
    private double[] notas;
    
    public Estudiante(String nombre, String[] materias) {
        this.nombre = nombre;
        this.materias = materias;
        this.notas = new double[materias.length];  // Todas en 0 al inicio
    }
    
    // GETTERS
    public String getNombre() { return this.nombre; }
    public String[] getMaterias() { return this.materias; }
    public double getNota(int indice) {
        if (indice >= 0 && indice < notas.length) {
            return notas[indice];
        }
        return -1;
    }
    
    public double getPromedio() {
        double suma = 0;
        for (double nota : notas) {
            suma = suma + nota;
        }
        if (notas.length > 0) {
            return suma / notas.length;
        }
        return 0;
    }
    
    // SETTER con validación
    public boolean setNota(int indice, double nota) {
        if (indice < 0 || indice >= notas.length) {
            System.out.println("❌ Índice inválido");
            return false;
        }
        
        if (nota < 0 || nota > 100) {
            System.out.println("❌ Nota inválida: " + nota);
            return false;
        }
        
        notas[indice] = nota;
        System.out.println("✅ " + materias[indice] + ": " + nota);
        return true;
    }
    
    public void mostrarBoletin() {
        System.out.println("📊 BOLETÍN: " + nombre);
        System.out.println("══════════════════");
        
        for (int i = 0; i < materias.length; i++) {
            String estado = notas[i] >= 70 ? "✅" : "❌";
            System.out.println(estado + " " + materias[i] + ": " + notas[i]);
        }
        
        double promedio = getPromedio();
        System.out.println("──────────────────────");
        System.out.println("Promedio: " + String.format("%.1f", promedio));
        System.out.println(promedio >= 70 ? "✅ APROBADO" : "❌ REPROBADO");
    }
}

// Archivo: Main.java
public class Main {
    public static void main(String[] args) {
        String[] materias = {"Mate", "Ciencia", "Historia", "Inglés"};
        Estudiante e = new Estudiante("Ana", materias);
        
        // Asignar notas (con validación)
        e.setNota(0, 85);
        e.setNota(1, 92);
        e.setNota(2, 78);
        e.setNota(3, 95);
        
        // Intentos inválidos
        e.setNota(-1, 50);   // Índice inválido
        e.setNota(0, 150);   // Nota inválida
        e.setNota(10, 80);   // Índice fuera de rango
        
        System.out.println();
        e.mostrarBoletin();
        
        // ❌ Esto da error (notas es private)
        // e.notas[0] = 999;  // ¡NO SE PUEDE!
    }
}
```

<ExerciseBlock id={5} title="Inventario con acceso controlado" difficulty="hard">
  Crea una clase `Inventario` con `private String[] nombres`, `private double[] precios`, `private int[] cantidades`. Solo modifica con métodos.

  <div slot="hint1">
    NO hay setters para los arrays. Solo `agregarProducto()`, `actualizarPrecio()`, `vender()`.
  </div>

  <div slot="hint2">
    Cada método valida antes de modificar.
  </div>

  <div slot="solution">
```java
// Archivo: Inventario.java
public class Inventario {
    private String nombreTienda;
    private String[] nombres;
    private double[] precios;
    private int[] cantidades;
    private int totalProductos;
    
    public Inventario(String nombreTienda, int capacidad) {
        this.nombreTienda = nombreTienda;
        this.nombres = new String[capacidad];
        this.precios = new double[capacidad];
        this.cantidades = new int[capacidad];
        this.totalProductos = 0;
    }
    
    // GETTERS
    public String getNombreTienda() { return this.nombreTienda; }
    public int getTotalProductos() { return this.totalProductos; }
    
    public double getPrecio(int indice) {
        if (indice >= 0 && indice < totalProductos) {
            return precios[indice];
        }
        return 0;
    }
    
    public int getCantidad(int indice) {
        if (indice >= 0 && indice < totalProductos) {
            return cantidades[indice];
        }
        return 0;
    }
    
    // MÉTODOS (no setters directos!)
    public boolean agregarProducto(String nombre, double precio, int cantidad) {
        if (totalProductos >= nombres.length) {
            System.out.println("❌ Inventario lleno!");
            return false;
        }
        
        if (precio <= 0 || cantidad < 0) {
            System.out.println("❌ Datos inválidos");
            return false;
        }
        
        nombres[totalProductos] = nombre;
        precios[totalProductos] = precio;
        cantidades[totalProductos] = cantidad;
        totalProductos++;
        
        System.out.println("✅ Producto agregado: " + nombre);
        return true;
    }
    
    public boolean actualizarPrecio(int indice, double nuevoPrecio) {
        if (indice < 0 || indice >= totalProductos) {
            System.out.println("❌ Índice inválido");
            return false;
        }
        
        if (nuevoPrecio <= 0) {
            System.out.println("❌ Precio inválido");
            return false;
        }
        
        precios[indice] = nuevoPrecio;
        System.out.println("✅ Precio actualizado: " + nombres[indice]);
        return true;
    }
    
    public boolean vender(int indice, int cantidad) {
        if (indice < 0 || indice >= totalProductos) {
            System.out.println("❌ Producto no encontrado");
            return false;
        }
        
        if (cantidad > cantidades[indice]) {
            System.out.println("❌ Stock insuficiente: " + nombres[indice]);
            return false;
        }
        
        cantidades[indice] = cantidades[indice] - cantidad;
        double ingreso = precios[indice] * cantidad;
        System.out.println("✅ Vendido: " + nombres[indice] + " x" + cantidad + " → $" + ingreso);
        return true;
    }
    
    public void mostrarInventario() {
        System.out.println("🏪 INVENTARIO: " + nombreTienda);
        System.out.println("══════════════════\n");
        
        double valorTotal = 0;
        
        for (int i = 0; i < totalProductos; i++) {
            double valor = precios[i] * cantidades[i];
            valorTotal = valorTotal + valor;
            
            System.out.println("[" + (i + 1) + "] " + nombres[i]);
            System.out.println("    Precio: $" + precios[i] + " | Stock: " + cantidades[i]);
            System.out.println("    Valor: $" + valor);
            System.out.println("");
        }
        
        System.out.println("──────────────────────");
        System.out.println("💰 Valor total: $" + valorTotal);
    }
}

// Archivo: Main.java
public class Main {
    public static void main(String[] args) {
        Inventario inv = new Inventario("Tech Store", 10);
        
        System.out.println("--- AGREGANDO ---\n");
        inv.agregarProducto("Laptop", 999.99, 10);
        inv.agregarProducto("Mouse", 25.50, 50);
        inv.agregarProducto("Teclado", 75.00, 0);
        
        System.out.println("\n--- ACTUALIZAR ---\n");
        inv.actualizarPrecio(0, 899.99);
        
        System.out.println("\n--- VENDER ---\n");
        inv.vender(0, 3);
        inv.vender(2, 5);  // Debería fallar (stock 0)
        
        System.out.println("\n--- ESTADO FINAL ---\n");
        inv.mostrarInventario();
        
        // ❌ Esto da error (todo es private)
        // inv.nombres[0] = "Hackeado";  // ¡NO SE PUEDE!
    }
}
```

<ExerciseBlock id={6} title="Simulador: Sistema de login con contraseñas" difficulty="hard">
  Crea una clase `Usuario` con `private String contraseña`. Métodos: `cambiarContraseña()`, `verificarContraseña()`.

  <div slot="hint1">
    La contraseña es private y solo se cambia con validación (mínimo 8 chars).
  </div>

  <div slot="hint2">
    `verificarContraseña(String)` retorna `boolean` si coincide.
  </div>

  <div slot="solution">
```java
// Archivo: Usuario.java
public class Usuario {
    private String nombre;
    private String email;
    private String contraseña;
    private int intentosFallidos;
    
    public Usuario(String nombre, String email, String contraseña) {
        this.nombre = nombre;
        this.email = email;
        this.setContraseña(contraseña);
        this.intentosFallidos = 0;
    }
    
    // GETTERS
    public String getNombre() { return this.nombre; }
    public String getEmail() { return this.email; }
    // NO hay getContraseña()!
    
    // SETTER con validación
    public boolean setContraseña(String nueva) {
        if (nueva.length() < 8) {
            System.out.println("❌ La contraseña debe tener al menos 8 caracteres");
            return false;
        }
        
        boolean tieneMayuscula = false;
        boolean tieneNumero = false;
        
        for (int i = 0; i < nueva.length(); i++) {
            char c = nueva.charAt(i);
            if (c >= 'A' && c <= 'Z') tieneMayuscula = true;
            if (c >= '0' && c <= '9') tieneNumero = true;
        }
        
        if (!tieneMayuscula || !tieneNumero) {
            System.out.println("❌ Necesita mayúscula y número");
            return false;
        }
        
        this.contraseña = nueva;
        System.out.println("✅ Contraseña actualizada");
        return true;
    }
    
    // MÉTODOS
    public boolean verificarContraseña(String pass) {
        if (this.contraseña.equals(pass)) {
            intentosFallidos = 0;  // Resetear intentos
            return true;
        } else {
            intentosFallidos++;
            System.out.println("❌ Contraseña incorrecta (intento " + intentosFallidos + ")");
            
            if (intentosFallidos >= 3) {
                System.out.println("🔒 Cuenta bloqueada por seguridad");
            }
            
            return false;
        }
    }
    
    public void mostrarInfo() {
        System.out.println("👤 " + nombre + " (" + email + ")");
        System.out.println("   Intentos fallidos: " + intentosFallidos);
    }
}

// Archivo: Main.java
public class Main {
    public static void main(String[] args) {
        Usuario user = new Usuario("Ana", "ana@email.com", "Secure1Pass");
        user.mostrarInfo();
        
        System.out.println("\n--- VERIFICANDO ---\n");
        user.verificarContraseña("wrong");
        user.verificarContraseña("wrong2");
        user.verificarContraseña("Secure1Pass");  // Correcta
        
        System.out.println("\n--- CAMBIANDO ---\n");
        user.setContraseña("123");         // Muy corta
        user.setContraseña("sinmayuscula");  // Sin mayúscula
        user.setContraseña("NuevaPass1");    // ✅ Válida
    }
}
```

```java
public class Semaforo {
    private String ubicacion;
    private int estado;  // 0=Rojo, 1=Amarillo, 2=Verde
    private int ciclos;
    
    public Semaforo(String ubicacion) {

        this.estado = 0;  // Empieza en Rojo

    }

    public String getUbicacion() { return this.ubicacion; }
    public int getCiclos() { return this.ciclos; }
    
    public String getEstado() {
        switch (estado) {
            case 0: return "🔴 Rojo";
            case 1: return "🟡 Amarillo";
            case 2: return "🟢 Verde";
            default: return "⚫ Error";
        }
    }
```

## 🚨 Errores Comunes y Soluciones

### Error: "has private access in"

**Problema**: Intentaste acceder a un atributo private desde fuera de la clase.

**Solución**: Usa el getter: `objeto.getAtributo()` en lugar de `objeto.atributo`.

### Error: El setter no valida

**Problema**: Tu setter acepta cualquier valor.

**Solución**: Agrega `if` para validar antes de asignar:
```java
public void setEdad(int edad) {
    if (edad > 0 && edad < 150) {  // ← Validación
        this.edad = edad;
    } else {
        System.out.println("❌ Edad inválida");
    }
}
```

### Error: Getter modifica datos

**Problema**: Tu getter devuelve una referencia mutable (como un array).

**Solución**: Devuelve una copia:
```java
public int[] getNotas() {
    return notas.clone();  // ← Copia, no referencia directa
}
```
